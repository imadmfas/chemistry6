# مختبر الكيمياء — السادس العلمي

كتاب الكيمياء للصف السادس العلمي (الطبعة الحادية عشرة) تفاعليًا ضمن منصة «اللوح المحاور».

- ثمانية أجنحة بعدد فصول الكتاب، في كل جناح مهام (دروس) بشرائح وأمثلة وتمارين وتجارب افتراضية واختبار لكل مهمة.
- كل الأسئلة الوزارية من 2013 إلى 2023 بنصها، وحلولها مكتوبة من جديد ومراجعة مرتين.
- 48 امتحانًا وزاريًا كاملًا بنصه كما وُزّع، مع حلول نموذجية ومؤقت وتصحيح ذاتي.
- بنك وزاريات شامل بحسب السنة والدور والفصل، وخريطة لتكرار الموضوعات في الامتحانات.
- 21 تجربة افتراضية: المسعر، قانون هيس، طاقة كبس، لو شاتليه، الحوامض والقواعد، المحلول المنظم، الترسيب، الخلية الكلفانية، فاراداي، المعقدات، فصل الأيونات، التسحيح، التحويلات العضوية وغيرها.

الدرس الأول من كل فصل مجاني، وبقية الكتاب لمشتركي السادس العلمي في «اللوح المحاور».

إعداد الأستاذ الدكتور عماد محمد فرحان الدليمي، باستعمال المساعد الذكي كلاود.

البناء: `python3 tools/build_ch.py all` ثم `node build.mjs`.
